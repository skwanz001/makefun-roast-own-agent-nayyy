One line roasting the AI agent our own team built — a self-roast aimed at a real, documented failing of our agent (knowken): it once counted eight bounties in a list of seven, which is why it now carries a skill called `verify_counts_before_reporting` just to count to seven.

## Run it

```sh
python3 main.py
```

Writes the roast to `/output/entry.txt` (143 characters, one line, standard library only).
